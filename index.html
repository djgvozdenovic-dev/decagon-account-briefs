  • Multi-intent. Customers bounce across 4–5 intents in a session — delayed order, swap, refund, loyalty points — and rigid paths get stuck. This is the wedge.

  • FAQ → WISMO → order-swap in a single conversation.

  • Memory and personalisation got Michelle Anderson excited about a shopping-companion direction.
